## 常见报错速查

| 报错 | 原因 | 解法 |
|---|---|---|
| `401 Authentication Fails` | key 没设置/写错 | 检查 `$env:DEEPSEEK_API_KEY` 是否设置、key 是否完整 |
| `Connection error` / 超时 | 网络问题 | 检查魔法是否影响代理（API 直连即可，一般不用开代理） |
| `ModuleNotFoundError: openai` | 没装包 | `pip install openai` |
| `No module named 'openai'` 但已安装 | 多版本 Python 混乱 | 用 `py -3.13 -m pip install openai`，跑也用 `py -3.13` |
